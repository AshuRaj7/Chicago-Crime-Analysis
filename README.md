# Chicago Crime Data Analysis & Dashboard

An end-to-end Python analytics and Flask web dashboard analyzing municipal Chicago crime incidents, arrest trends, and temporal patterns.

## Features
- Automated data ingestion, cleaning, and preprocessing pipeline.
- Interactive Flask dashboard visualizing temporal trends and hotspot locations.
- SQL-backed query layer for dynamic incident metrics.

## Tech Stack
- Python, Flask, Pandas, SQLite, Matplotlib, HTML/CSS

pip install -r requirements.txt
